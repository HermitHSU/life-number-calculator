# 生命靈數手機排盤

完整、可離線執行的靜態網頁原始碼，繁體中文介面，支援手機與電腦。

## 開啟方式

1. 解壓縮 ZIP，保留所有檔案在同一個資料夾。
2. 使用瀏覽器開啟 `index.html`，填寫生日，按「開始排盤」。
3. 手機若以檔案預覽器開啟而無法執行 JavaScript，請改用支援本機網頁的瀏覽器，或把完整資料夾放到靜態網頁主機，再用手機瀏覽網址。無需建置或安裝套件。

生日必填；姓名、性別、出生時間及備註選填，均不參與運算。頁面不使用網路請求、Cookie、本機儲存或外部套件；重新整理後需重新輸入。可使用「列印／PDF」保留結果，PDF 選項由裝置的列印功能提供。

## 檔案

- `index.html`：頁面與表單。
- `engine.js`：獨立純計算引擎，同時支援一般瀏覽器與 Node.js。
- `app.js`：表單驗證、結果呈現及列印操作。
- `styles.css`：手機響應式樣式與列印樣式。
- `test-engine.js`：可執行驗算與日期驗證。
- `README.md`：使用方法及公式說明。

## 公式規格

`r(n)` 為反覆相加十進位各位數，直到剩下一位數；例如 r(19)=1、r(12)=3、r(0)=0。不保留 11、22 等大師數。

- A = r(生日日期)，B = r(月份)。
- D = r(四位西元年前兩位)，E = r(後兩位)。例如 1984 → D=r(19)=1、E=r(84)=3。
- C=r(A+B)，F=r(D+E)，G=r(C+F)。
- H=r(F+G)，I=r(C+G)，J=r(H+I)。
- K=r(A+C)，L=r(B+C)，M=r(K+L)。
- N=r(D+F)，O=r(E+F)，P=r(N+O)。

12 組順序固定為：ABC、DEF、CFG、CGI、FGH、HIJ、ACK、BCL、KLM、DFN、EFO、NOP。每組為三個個位數的字串串接，不是把三位數再相加。第 3 組 CFG 稱「主性格」。

第 13 組隱藏號為 r(C×2)、r(F×2)、r(G×2) 依序串接。

缺失數字：只查看 A～G 已出現的數字，再從 1～9 中排除它們；H～P、組合數字及隱藏號均不加入判定。

G 稱「生命靈數」；A／E／G 稱「星號數字」（保留位置及重複數字）；r(A+E+G) 稱「本源夢想」。

日期採西元曆，接受 0001～9999 年的有效日期，包含閏年驗證。年份部分或加法得到 0 時保留 0，不另改為 9。

## 81 組解說（2026-10-23）

analysis.js 內含 81 組三位數的完整解說，沿用使用者「挖掘数字易经组合含义」對話（https://chatgpt.com/c/6adb5d62-767c-83ec-bf0f-06f81439ca94）整理內容。12 組命理項目與第13項隱藏號碼皆按實際數值查表，不把逆序數字視為相同組合。含 0 等未收錄組合會明示暫無對應分析。解說為民俗詮釋，並非科學人格測驗。

原始核心解說與後續整理的八大面向分開保存。計算引擎與公式保持不變。

## 八大面向與溝通建議

communication.js 為81組建立核心性格、內在需求、溝通風格、決策模式、信任建立、抗拒與防衛、人際互動、行動建議。每組另有一個不同的確認問題，以及開場提問、提案方式、疑慮處理、後續追蹤、避免方式五類業務範例。

核心性格保留 analysis.js 的原始解說。其餘面向是本次依原解說整理的溝通假設，並非原對話已逐組提供的內容，也不是已驗證的人格結論。逐組設定待確認需求、互動風險、小步行動與提問，再按12類溝通主題使用一致的策略；不同組合可能共用適合的溝通策略。應以當事人實際回應確認與調整，不使用數字斷言需求或施壓成交。

12組及隱藏號都有可展開的分析卡；預設展開主性格，支援展開／收合全部。更換生日時重建分析，避免保留前一組內容；未收錄組合明示缺少資料。列印時展開全部分析，結束後恢復原狀。

維護：修改 scripts/build-communication.cjs 的逐組資料與策略後執行 node scripts/build-communication.cjs，再執行 node test-communication.js 及 node test-engine.js。測試涵蓋81組、八大面向、原文一致性、81個不同提問、405個業務欄位、逆序差異及缺漏組合。
